# 軽天拾い出し（keiten-estimator）

PDFの図面を読み込んで、**軽天工事の拾い出し（数量積算）** を行うブラウザ用Webアプリです。
材料の本数ではなく、**部屋ごとの面積・延長**を根拠つきで拾い出します。

## 拾い出す項目（部屋ごと）

| 項目 | 単位 | 内容 |
|---|---|---|
| 天井下地 | m² | 天井面積（平面図／天伏図から） |
| 天井ボード | m² | **種類別**（重ね貼り対応：例 岩綿吸音板＋PB下貼り） |
| 壁下地 | m² | 壁延長 × 壁高さ（壁を1本ずつ拾う） |
| 壁ボード | m² | **種類別**・面数（片面／両面） |
| 開口補強 | m | 建具表を見て入力。ドア＝2×高＋幅、窓＝2×高＋2×幅 |

> 例）壁高さ3m・開口幅900mmのドア → 開口補強 = 2×3＋0.9 ＝ **6.9m**

結果は **室別の拾い出し表**（根拠つき）と **全体合計**（種類別）で表示し、CSV出力できます。

> ⚠️ 自動検出は **ベクター（CADエクスポート）PDF** で精度が高くなります。スキャン画像PDFは
> 線・寸法情報を持たないため、その場合は「2点校正」＋手動作図でご利用ください。

## 使い方

```bash
npm install
npm run dev      # 開発サーバ（http://localhost:5173）
npm run build    # 本番ビルド（dist/）
npm test         # ユニットテスト（vitest）
npm run verify   # 実PDFでの通し検証
```

### 操作の流れ
1. **「PDFを開く」** で図面を読み込む。縮尺と室（矩形）が自動検出されます。
2. **縮尺の確認**：自動検出されない場合は上部「1/」欄に分母を入力、または **「2点校正」** で
   既知寸法2点をクリックして実寸(mm)を入力。
3. **「ボード種類」タブ** で使うボード種類を登録（せっこうボード9.5/12.5、岩綿吸音板 等）。
4. **「室・壁・開口」タブ** で各室を編集：
   - 天井：面積（図面から自動 or 手入力）・天井高・**天井ボード（複数追加可）**
   - 壁：**「壁を描く」** で図面上に1本ずつ引く、または「周長から壁生成」「＋壁を追加（手入力）」。
     壁ごとに延長・高さ・面数・**ボード種類（複数）**・壁下地計上の有無を設定。
   - 開口：建具表を見て、幅・高さ・数を入力（ドア／窓）。
5. **「拾い出し」タブ** で室別明細＋合計を確認 → **「CSV出力」**。

## 自動検出の仕組み
- **縮尺**：テキスト中の `1/100`・`1:50`・`S=1/100` 等を抽出。PDFが正寸（1pt=1/72inch）である
  前提で `実mm/pt = 0.3528 × 分母` に換算。
- **室**：PDFのベクター描画命令（`getOperatorList`）を解析し、変換行列を追跡して線分を復元 →
  軸平行な矩形を検出。内包するテキストを室名に採用。

## 算定の前提（既定値）
- **開口控除は既定でオン**。各開口に「対象壁」を選ぶと、その壁の壁下地・壁ボードから
  開口面積を差し引きます。**ボードは面数ぶん控除**（両面なら開口も両面分）。
  対象壁が未指定の開口は控除せず、開口補強の延長のみ計上します。
- 面積拾いに **ロス率は掛けていません**（材料数量へ換算する際に別途見込んでください）。
- 開口補強：ドア＝2×高＋幅、窓＝2×高＋2×幅。
- いずれも一般値です。**確定積算では物件の仕様書を優先してください。**

## 技術構成
- Vite + React + TypeScript
- [pdfjs-dist](https://github.com/mozilla/pdf.js)（PDFレンダリング・テキスト/ベクター抽出）
- 算定ロジック `src/estimate/`、幾何処理 `src/geometry.ts`、PDF解析 `src/pdf/`

## テスト
- `src/__tests__/geometry.test.ts` — 面積・周長・矩形検出
- `src/__tests__/estimate.test.ts` — 天井/壁/ボード/開口補強の拾い出し・集計
- `src/__tests__/extract.test.ts` — pdf.jsの実OPS定数を用いたベクター解析・縮尺検出
- `scripts/verify-extract.ts` — 実物のベクターPDFを生成し、検出→拾い出しまでを通しで検証

## 制限事項 / 今後
- スキャン画像PDFの自動寸法認識（OCR/画像CV）は未対応 → 手動作図で対応。
- 建具表の自動読み取りは未対応 → 開口は手入力。
- 斜め壁・曲線部屋は矩形自動検出の対象外 → 手動作図で対応。
- 面積→材料数量（野縁・スタッド本数等）への換算は今後の拡張予定。
