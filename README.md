# 積算AI（sekisan-ai）

PDF図面を **Claude のビジョンAI** に読み取らせ、**部屋ごとに軽天・ボード工事の数量を自動で拾い出す** Webアプリです。
AIが下拾い → 画面で確認・修正 → CSV出力、という流れで使います（KK Generation「積算AI」と同じ発想）。

- **入力**: PDF（平面図・天井伏図・建具表・仕上表など）
- **AIが拾うもの（部屋ごと）**: 天井下地㎡ / 天井ボード種類別㎡ / 壁下地㎡ / 壁ボード種類別㎡ / 開口補強m
- **出力**: 室別明細＋合計（種類別）、CSV
- **APIキーが無くても**サンプルモードでUIを試せます

> ⚠️ これはAIによる「下拾い」です。**必ず人が確認・修正**してから使ってください。精度は図面の状態により変動します。

## 必要なもの
- Node.js 20 以上（推奨）
- Anthropic の APIキー（下記参照）。無くてもサンプルモードで起動はできます。

## セットアップ
```bash
npm install
cp .env.example .env      # Windowsは: copy .env.example .env
# .env をテキストエディタで開き、ANTHROPIC_API_KEY=sk-ant-... を貼り付けて保存
npm run dev
```
ブラウザで **http://localhost:5173** を開く（PowerShellは開いたままに）。
`npm run dev` でフロント（5173）とAPIサーバ（8787）が同時に起動します。

## APIキーの取得と料金の目安
1. https://console.anthropic.com にアクセスしてアカウント作成
2. 支払い方法を登録（クレジット前払い式）
3. 「API Keys」で新しいキーを発行 → `.env` の `ANTHROPIC_API_KEY` に貼り付け

**料金の目安（1ページの解析あたり）**
- 既定モデル `claude-opus-4-8`（高精度）: おおよそ **15〜30円** 程度／ページ
- `claude-sonnet-4-6`（コスト重視）: おおよそ **8〜15円** 程度／ページ（`.env` の `ANTHROPIC_MODEL` で切替）

※ 図面の情報量・出力量で増減します。正確な課金は Anthropic コンソールで確認できます。
従量課金なので、使った分だけの支払いです。

## 使い方
1. **PDFを開く** → ページを送って解析したい図面（天伏図/平面図など）を表示
2. 必要なら**補足**を入力（例：「天伏図。壁下地はスラブまで、ボードは天井下まで」）
3. **「このページをAIで拾う」** → 部屋ごとの数量が表示される
4. **内容を確認・修正**（AIの下拾いなので必ずチェック）。室・ボード・開口を追加/編集可
5. **CSV出力**

## 仕組み
- フロント（React + pdfjs）がPDFページを画像（PNG, 長辺〜2200px）に描画
- 画像を APIサーバ（Express）へ送信 → サーバが Claude のビジョンAIに構造化出力で問い合わせ
- Claude が室名・寸法・縮尺・建具表・仕上表を読み取り、部屋ごとの数量をJSONで返す
- APIキーは**サーバ側（.env）だけ**で扱い、ブラウザには出しません

## 構成
- `server/index.mjs` — Express APIサーバ（`/api/analyze`）
- `server/schema.mjs` — 構造化出力スキーマ＋AIへの指示（プロンプト）
- `server/mock.mjs` — キー未設定時のサンプルデータ
- `src/` — フロント（PDF描画・編集UI・CSV出力）

## テスト
```bash
npm test        # 集計・CSVのユニットテスト
npm run build   # 型チェック＋本番ビルド
```

## 制限事項 / 今後
- スキャンが粗い・手書き・縮尺記載なしの図面は精度が落ちます（信頼度low表示＋要確認）。
- 建具表/仕上表が別ページの場合は、それぞれのページでも解析するか補足欄で伝えてください。
- 複数ページ横断の自動統合、Excel(.xlsx)直接出力、明細書様式テンプレートは今後の拡張候補です。
