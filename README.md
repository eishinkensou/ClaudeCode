# 軽天積算（keiten-estimator）

PDFの図面を読み込んで、**軽天工事（天井下地・間仕切壁LGS）とボード貼り**の数量を
自動で拾い、積算するブラウザ用Webアプリです。

- **対象**: 天井（軽天 / 野縁・野縁受け方式）、間仕切壁（LGS / ランナー・スタッド方式）、ボード貼り
- **方式**: PDF（特にCADエクスポートのベクター図面）から **縮尺・部屋・寸法を自動検出** し、
  検出結果を画面上で確認・修正してから積算。自動検出が効かない図面でも、
  2点校正＋手動作図で拾えます。
- **出力**: 領域別明細＋材料別合計を画面表示、CSV出力（Excel対応・BOM付き）

> ⚠️ 自動検出は **ベクターPDF** で精度が高くなります。スキャン画像PDFは線・寸法情報を
> 持たないため自動検出は効きません。その場合は手動作図モードをご利用ください。

## 使い方

```bash
npm install
npm run dev      # 開発サーバ（http://localhost:5173）
npm run build    # 本番ビルド（dist/）
npm run preview  # ビルド結果をプレビュー
npm test         # ユニットテスト（vitest）
```

ブラウザでアプリを開いたら:

1. **「PDFを開く」** で図面を読み込む。縮尺（`1/100` 等のテキスト）と部屋（矩形）が自動検出されます。
2. **縮尺の確認**: 自動検出されない場合は、上部の「1/」欄に分母を入力するか、
   **「2点校正」** で図面上の既知寸法2点をクリックして実寸(mm)を入力。
3. **領域の確認・修正**: 右の「領域」タブで、各領域の名称・種別（天井/間仕切壁/ボード）・
   壁高さ・ボード貼り共の有無を編集。検出漏れは **「天井を描く」「壁を描く」** で手動追加。
4. **仕様設定**: 「仕様設定」タブで野縁・スタッドのピッチ、定尺長、ロス率などを調整。
5. **積算結果**: 「積算結果」タブで明細と合計を確認し、**「CSV出力」** で書き出し。

## 積算モデル（算定根拠）

初期値は一般的な標準仕様です。**確定積算では必ず物件の仕様書に合わせて調整してください。**

### 天井（軽天） — 面積 A[m²] から
| 材料 | 算定式 |
|---|---|
| 野縁 | 延長 = A / 野縁ピッチ |
| 野縁受け | 延長 = A / 野縁受けピッチ |
| 吊りボルト・ハンガー・インサート | A / (ピッチ × ピッチ)（格子配置） |
| クリップ | A / (野縁ピッチ × 野縁受けピッチ)（交点数） |
| ボード | A × (1+ロス) / 1枚面積 |

定尺材の本数 = 延長 × (1+ロス) / 定尺長（切上げ）。

### 間仕切壁（LGS） — 延長 L[m]・高さ H[m] から
| 材料 | 算定式 |
|---|---|
| ランナー | 延長 = L × 2（上下） |
| スタッド | 本数 = floor(L / ピッチ) + 1、各本 = H |
| 振れ止め | 段数 = floor(H / 段ピッチ)、各段 = L |
| スペーサー | スタッド本数 × round(H / スペーサーピッチ) |
| ボード | 片面面積 = L × H、面数（両面=2）で倍化 |

### 自動検出の仕組み
- **縮尺**: テキスト中の `1/100`・`1:50`・`S=1/100` 等を抽出。PDFが正寸（1pt=1/72inch）
  である前提で `実mm/pt = 0.3528 × 分母` に換算。
- **部屋**: PDFのベクター描画命令（`getOperatorList`）を解析し、変換行列を追跡して
  線分を復元 → 軸平行な矩形を検出。内包するテキストを部屋名に採用。
- **寸法**: テキスト位置（`getTextContent`）を抽出して名称・寸法の判別に利用。

## 技術構成

- Vite + React + TypeScript
- [pdfjs-dist](https://github.com/mozilla/pdf.js)（PDFレンダリング・テキスト/ベクター抽出）
- 算定ロジックは `src/estimate/`、幾何処理は `src/geometry.ts`、PDF解析は `src/pdf/` に分離。

## テスト

- `src/__tests__/geometry.test.ts` — 面積・周長・矩形検出
- `src/__tests__/estimate.test.ts` — 天井/壁/ボードの数量算定・集計
- `src/__tests__/extract.test.ts` — pdf.jsの実OPS定数を用いたベクター解析・縮尺検出
- `scripts/verify-extract.ts` — 実物のベクターPDFを生成し、検出→積算までを通しで検証
  （`npx tsx scripts/verify-extract.ts`）

## 制限事項 / 今後

- スキャン画像PDFの自動寸法認識（OCR/画像CV）は未対応。手動作図で対応。
- 斜め壁・曲線部屋は矩形検出の対象外（手動作図で対応）。
- 開口部（建具）の下地補強・天井段差・斜め天井などの特殊納まりは別途加算が必要。
