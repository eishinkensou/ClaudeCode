# Windows PC 高速化・McAfee 削除・Defender 有効化 手順書

このフォルダーのスクリプトは、以下の依頼内容をそのまま実行するために作成したものです。

1. 読み取りのみの診断
2. 重い原因の特定（診断結果をもとに報告）
3. McAfee 製品（通常版・Store 版）の全削除と MCPR 案内
4. Windows Defender のサービス・リアルタイム保護の有効化と定義更新
5. 一時ファイル削除・ストレージセンサー有効化・DISM / sfc・ディスク最適化
6. スタートアップ無効化・アプリ削除（対象提示 → 確認 → 実行）
7. 実施内容・改善結果・再起動要否の報告

> **重要**: Claude のクラウドセッションからは Windows PC を直接操作できません。
> 下記のとおり PC 上で PowerShell を実行し、出力結果を Claude に貼り付けてください。
> Claude のアプリを削除・再インストールしても状況は変わりません（原因はアプリの不具合ではなく、実行場所がクラウドであるためです）。

## 共通の準備（毎回）

1. `スタート` → `PowerShell` または `ターミナル` を右クリック → **管理者として実行**
2. 以下を実行してこのフォルダーへ移動し、スクリプトの実行を一時的に許可
   ```powershell
   cd "<このフォルダーのパス>"
   Set-ExecutionPolicy -Scope Process Bypass -Force
   ```

## Step 1: 診断（読み取りのみ・変更なし）

```powershell
.\01-diagnose.ps1
```
- デスクトップに `PC診断_日付.txt` が作成されます。
- **このファイルの内容を Claude に貼り付けてください。** 重い原因を特定して報告します（Step 2）。

取得項目: OS / メモリ / CPU / ディスク種別と空き容量 / CPU・メモリ上位プロセス / スタートアップ登録 / 登録済みウイルス対策 / McAfee のインストール状況とサービス / Defender の状態 / 電源プラン / 再起動待ち更新 / 直近のシステムエラー / インストール済みアプリ

## Step 3: McAfee の削除

```powershell
.\02-remove-mcafee.ps1
```
- 検出された McAfee 製品を一覧表示し、`y` を入力すると順にアンインストールします。
- McAfee のアンインストーラーは画面上で確認を求めることがあります。指示に従って完了させてください。
- 終了時に残骸をチェックし、残っていれば **MCPR** の実行を案内します。
  - 公式サポート: <https://www.mcafee.com/support/> で「MCPR」を検索
  - ダウンロード（公式）: <https://download.mcafee.com/molbin/iss-loc/SupportTools/MCPR/MCPR.exe>
  - `MCPR.exe` を右クリック → 管理者として実行 → 同意 → 表示文字を入力 → 完了後 **再起動**
- **削除後は必ず再起動**してください（他社製ウイルス対策が残っていると Defender は有効化できません）。

## Step 4: Windows Defender の有効化（再起動後）

```powershell
.\03-enable-defender.ps1
```
- 無効化ポリシーの解除 → サービス起動 → リアルタイム保護 ON → 定義ファイル更新 → 状態表示 → 任意でクイックスキャン。

### スクリプトで有効化できない場合（改ざん防止が効いている場合）の手動手順
1. `設定` → `プライバシーとセキュリティ` → `Windows セキュリティ` → `ウイルスと脅威の防止`
2. `ウイルスと脅威の防止の設定` → `設定の管理` → **リアルタイム保護** を ON
3. `ウイルスと脅威の防止の更新` → `更新プログラムのチェック`

## Step 5: クリーンアップとシステム修復

```powershell
.\04-cleanup-repair.ps1
```
- 一時ファイル・Windows Update キャッシュ・ごみ箱・ディスク クリーンアップ → ストレージ センサー有効化（毎週）→ `DISM /RestoreHealth` → `sfc /scannow` → SSD は TRIM / HDD はデフラグ → 電源プランをバランスに設定。
- 所要 20〜60 分。デスクトップに `PC修復ログ_日付.txt` が残ります。
- sfc / DISM が修復を行った場合は再起動が必要です。

## Step 6: スタートアップ無効化・アプリ削除（確認制）

```powershell
.\05-startup-review.ps1                       # 一覧表示のみ（変更なし）
```
- 表示された一覧を Claude に貼り付けてください。無効化・削除の候補を提示します。
- 合意した対象だけを指定して実行します（1件ごとに y/N の確認あり）。
  ```powershell
  .\05-startup-review.ps1 -Disable "OneDrive","Spotify"
  .\05-startup-review.ps1 -Uninstall "アプリの表示名"
  ```
- 無効化は Task Manager の「スタートアップ」タブと同じ仕組みで、いつでも戻せます。

## Step 7: 結果報告

Step 5 完了後に再度 `.\01-diagnose.ps1` を実行し、**前後の診断ファイル**を Claude に貼り付けてください。
実施内容・改善結果（空き容量、起動項目数、Defender 状態など）・再起動の要否をまとめて報告します。

## よくある「重い」原因（診断で確認するポイント）

| 症状 | 診断ファイルの見どころ |
|---|---|
| 起動・全体が遅い | ディスク種別が HDD / 空き容量 10% 未満 / スタートアップ登録が多い |
| 常に重い | メモリ使用率 85% 以上 / McAfee・他社製 AV のプロセスが CPU・メモリ上位 |
| 時々固まる | ディスク負荷 `% Disk Time` が常時高い / システムエラーにディスク関連イベント (ID 7, 51, 129, 153) |
| 更新後に遅い | 再起動待ちの更新あり / `TiWorker`・`MsMpEng` が CPU 上位 |
| ノート PC が遅い | 電源プランが「省電力」 |
