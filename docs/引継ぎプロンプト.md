あなたは建設の積算支援Webアプリ「**積算AI（sekisan-ai）**」の開発を引き継ぐエンジニアです。これまでの経緯と現状を理解し、私の指示に沿って機能追加・修正を続けてください。

## プロダクト概要
PDF図面を **Claude のビジョンAI** に読ませ、**部屋ごとに軽天（軽量鉄骨下地）・ボード工事の数量を自動で拾い出す**Webアプリ。「AIが下拾い → 人が画面で確認・修正 → CSV出力」という流れ。商用の KK Generation「積算AI」と同じ発想を汎用Claudeで実現したもの。**AIの出力は必ず人が確認する前提**（精度は図面の縮尺・解像度・記載情報に依存）。

## 技術構成
- フロント: Vite + React + TypeScript、`pdfjs-dist`（PDFをページ画像に描画、編集UI、CSV出力）
- バック: Express（`server/index.mjs`）。**APIキーはサーバ側 `.env` のみで保持**しブラウザに出さない。`/api/health` と `/api/analyze` を提供。`npm run dev` で Vite(5173) と APIサーバ(8787) が同時起動（Viteが /api を 8787 へプロキシ）
- AI: Anthropic SDK（`@anthropic-ai/sdk` 最新）。モデルは **`claude-opus-4-8`**（`.env` の `ANTHROPIC_MODEL` で `claude-sonnet-4-6` に変更可）。**コスト理由で勝手にモデルを下げないこと**（ユーザーの判断）。
  - ビジョン（図面画像 base64）+ **structured outputs**（`zodOutputFormat` + zod/v4 スキーマ）+ adaptive thinking + `effort: medium`
  - `client.messages.stream(...).finalMessage()` で取得（`max_tokens: 48000`）。`thinking:{type:"adaptive"}` のみ可（`budget_tokens` や temperature 等は Opus 4.8 では 400 になる）

## 主要ファイル
- `server/index.mjs` … APIサーバ。`/api/analyze` は `images[]`（複数ページ）を受け、ラベル付きで並べて Claude に渡す。キー未設定なら `server/mock.mjs` を返す
- `server/schema.mjs` … 構造化出力スキーマ（`Takeoff`）＋ システムプロンプト（積算担当者の役割・拾い方・複数図面の相互参照・位置情報bbox）
- `server/mock.mjs` … キー未設定時のサンプル
- `src/App.tsx` … 画面本体。PDF表示・ページ送り・「解析セット」（複数ページを集めて一括解析）・図面への**色枠オーバーレイ**（SVG）
- `src/components/ResultEditor.tsx` … 結果の編集UI＋合計（色スウォッチ・📍位置ジャンプ）
- `src/pdf.ts`（ページ→PNG, 長辺2576px）/ `src/api.ts` / `src/export.ts`(CSV) / `src/totals.ts`(集計) / `src/colors.ts`(配色) / `src/types.ts`

## データモデル（拾い出し）
室(Room)ごとに: 天井下地㎡ / 天井ボード（種類別）/ 壁下地㎡ / 壁ボード（種類別・面数）/ 開口（建具: 幅・高・数・補強m）/ 開口補強計m / notes / **regionPage（位置の平面図ページ）+ bbox(正規化0〜1の室範囲, 色枠照合用)**。
合計は種類別に集計（`src/totals.ts`）。CSVは室別明細＋合計＋BOM付き。

## ドメインの約束（積算の考え方）
- 床面積 ≒ 天井面積
- 壁: 延長 × 高さ = 面積。**下地高さとボード高さは別**（例「下地=スラブまで(階高)、ボード=天井下まで(天井高)」または「下地・ボード共にスラブまで」）。断面図/特記から判断
- 開口補強: ドア = 2×高さ + 幅、窓 = 2×高さ + 2×幅
- 開口は下地・ボードの面積から控除する考え方（ボードは面数ぶん）
- ボード種別は**仕上表**から、開口は**建具表**から、天井高・ふところは**天伏図/断面図**から補完
- 面積が読めない時は**面積表/求積図**を使うのが最有効

## これまでの到達点
- 複数ページ相互参照の解析、仕上表からのボード種別読み取りは良好
- 図面に色分け枠を重ねて結果と照合（同色対応、📍ジャンプ、枠/カード選択でハイライト）
- 堅牢化: 出力切れ対策（ストリーミング+max_tokens拡大+切れ時の親切なエラー）、長時間解析のタイムアウト解除（Vite proxy + Express）、空応答ハンドリング、ページ過多警告/全消去、高解像度化(2576px)

## 既知の課題 / 次の候補（優先度順の目安）
1. 1/300など小縮尺で面積・延長が0になりがち → **面積表/求積図の活用** と **範囲を拡大して解析（クロップ）** 機能
2. 色枠の位置精度向上（手動ドラッグ修正、囲んだ範囲だけ再解析）
3. 壁高さ（スラブ/天井下）の自動判定強化
4. フロア・区画ごとに解析→CSV合算の運用、複数ページ結果の統合・保存
5. Excel(.xlsx)直接出力、内訳明細書様式テンプレ
